달빛신전 모바일 웹 이동 테스트

PC: index.html을 브라우저로 여세요. 방향키/WASD 또는 마우스로 조이스틱을 사용합니다.
모바일: 이 폴더 전체를 정적 웹 서버에 올리고 휴대폰 브라우저로 접속하세요.
같은 Wi-Fi에서 테스트하려면 이 폴더에서 아래 명령으로 서버를 실행할 수 있습니다(Node.js 필요).
  node serve.cjs
PC: http://localhost:8080
휴대폰: http://PC의-Wi-Fi-IP주소:8080
Windows 방화벽과 Wi-Fi 설정에 따라 휴대폰 접속 허용이 필요할 수 있습니다.
서버 종료: Ctrl+C

기존 달빛신전 배경과 토끼 4프레임 이미지를 assets 폴더로 복사했습니다.
기존 walk-area.json을 별도 JavaScript 데이터로 복사해 바닥 이동 경계를 적용했습니다.
세로/가로 화면에 맞춰 신전 전체를 표시합니다. 손을 떼거나 앱을 전환하면 이동이 멈춥니다.
구현 범위: 화면 표시, 터치 조이스틱, 이동 애니메이션, PC 이동, 시작 위치 복귀.
전투, 보상, NFC, 계정, 기존 Windows 연결 프로그램은 포함하지 않습니다.
